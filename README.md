# FITTING — 手持ちアイテムからコーデ提案

服やファッション小物の写真から8つの表参道きれいめカジュアルを提案し、写真がなくても天気・季節トレンド・好みのカラーから、表参道スタイルを15案自動提案するStreamlitアプリです。上質なベーシックを軸に、レイヤード・丈感・素材ミックスを大胆に効かせます。自撮り写真からメンズ髪型を診断する機能もあります。

## 起動方法

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
streamlit run app.py
```

`.env` を開き、`OPENAI_API_KEY=...` の右側を自分のAPIキーに置き換えて保存してください。アプリ起動時に `.env` を読み込みます。`.env` は `.gitignore` に登録済みなので、GitHubへpushしないでください。Renderでは `.env` をアップロードせず、Renderの環境変数に `OPENAI_API_KEY` を登録してください。環境変数が `.env` の値より優先されます。任意で `OPENAI_VISION_MODEL` を指定でき、既定の画像対応モデルは `gpt-4.1-mini` です。

お気に入りサイトの永続保存には、TursoのSQLite互換データベースを使います。Tursoでデータベースと認証トークンを作成し、`.env` に `TURSO_DATABASE_URL` と `TURSO_AUTH_TOKEN` を設定してください。Renderでは同じ2つの値をサービスの環境変数に設定します。認証トークンはソースコードやチャットに貼らないでください。データベース内のURL保存テーブルは、設定後にお気に入り画面を開いたとき自動作成されます。

## Renderへのデプロイ

リポジトリをGitHubにpushしてRenderでBlueprintとして作成すると、ルートの `render.yaml` の設定でデプロイできます。Renderのサービス設定で `OPENAI_API_KEY` にOpenAI APIキーを登録してください。また、お気に入りサイトを使うにはTursoでデータベースと認証トークンを作成し、Renderの `TURSO_DATABASE_URL` と `TURSO_AUTH_TOKEN` に設定してください。Blueprintではこれらに `sync: false` を指定しており、秘密情報をソース管理へ登録しません。環境変数を登録すると、アプリはサーバー側のAPIキーを使い、アプリ内のAPIキー入力欄は表示しません。認証は設定していないため、RenderのURLを知っている人は誰でも利用でき、提案の実行でAPI利用料が発生する可能性があります。

無料プランは一定時間アクセスがないと休止し、次のアクセス時に起動待ちが発生する場合があります。

## できること

- 写真がなくても、選択したスタイル・カラーと天気／季節トレンドから、表参道きれいめカジュアルを中心に15案を自動提案（コーデ提案時の写真解析APIは不要）
- JPEG、PNG、WebPのアイテム写真を最大8枚まとめてアップロード（1枚30MB以下、合計60MB以下）。JPEGは最大250MP、PNG／WebPは最大80MPまで自動縮小
- 背面カメラを初期選択する専用カメラUIで、写真を1枚ずつ撮影・追加して最大8枚までまとめて提案（前後切替と前面カメラへのフォールバックに対応）
- 選んだ写真すべてを一つの手持ちワードローブとして読み取り、アイテムの種類や見える色を説明
- 写真に写ったアイテムを幅広く使い、表参道きれいめカジュアルを土台にシルエット・丈感・素材ミックスを大胆に効かせたコーデを8パターン提案
- 各案に具体的なインナーと、首元・袖口・裾から見せるレイヤード方法を提案。写真にないインナーは追加候補として明記
- 各パターンに、写真にないプラスワン候補と追加するメリットを提案
- 各案にブラックスピネルのネックレス、セイコーまたはロンジンの自動巻き時計、黒の厚底靴を提案
- 写真ありの8案・写真なしの15案とも、各コーデのボタンからAIイメージ画像を1案ずつ個別に生成
- メンズ、レディース、ユニセックスと好みのカラーを選択
- iPhoneなど幅の狭い画面では文字・入力欄・タップ領域を調整し、複数列の内容を縦に並べて表示。カメラは縦画面に合わせて大きく表示
- 別画面のメンズ髪型診断で、自撮り写真から見える輪郭・髪の特徴を参考に10案を提案
- 「今の髪型でセット」5案と「美容室でカット」5案を分け、セット方法や美容師へのオーダーを表示（パーマ・カラー等の薬剤施術は提案しません）
- 各案のボタンから、本人写真を参考にした前・横・後ろの3方向イメージを1枚ずつ生成
- 別画面のお気に入りサイトで、サイト名・URL・グループを登録し、タブ別に表示・編集・削除
- 日本の主要都市の現在天気を画面に表示し、任意でコーデに反映。取得失敗時は前年同月の平均気温を季節参考値として利用
- 2026年秋冬の海外ストリート／ランウェイ記事を参考に、配色やレイヤードを提案

## データとおすすめについて

画像はファイル選択またはブラウザーのカメラで用意できます。ファイル選択では最大8枚（1枚30MB以下、合計60MB以下）をまとめて選択できます。カメラは背面を初期にし、前後カメラの切替と、背面カメラがない端末での前面カメラへのフォールバックに対応しています。撮影した写真の「撮影した写真を追加」を押すと続けて撮影でき、最大8枚まで追加できます。カメラを使う場合は、ブラウザーのカメラ使用を許可してください。Renderなどにデプロイしたアプリでカメラを使うにはHTTPS接続が必要です。画像解析はOpenAI Chat Completions API、イメージ画像はOpenAI Images APIを利用します。高解像度JPEGは最大250MP、PNG／WebPは最大80MPまで読み込み後に長辺1280pxへ縮小してJPEGに変換し、写真からの提案ボタンを押すと選択した写真すべてをまとめてOpenAIへ送信します。複数枚を解析すると画像解析のAPI利用料が増えることがあります。撮影・アップロードした写真はセッション中に一時保持しますが、ファイルには保存しません。写真なしのコーデ提案は天気・季節トレンドを使ったローカル処理で、OpenAI APIを呼び出しません。写真ありの8案・写真なしの15案とも、提案カードの「このコーデのイメージ画像を生成」を押したときだけ、選んだ案の説明文から画像を1枚生成します。写真なしの画像生成では、アップロード写真は送信せず、コーデ説明のみをOpenAI Images APIへ送信します。画像生成ごとにAPI利用料が発生する場合があります。生成した画像はセッション中だけ保持し、アプリはファイルに保存しません。任意で `OPENAI_IMAGE_MODEL` を指定でき、既定は `gpt-image-1` です。APIの利用料金・データ取り扱いはOpenAIの契約と設定に従います。

メンズ髪型診断では、前面カメラで撮影した自撮り写真をOpenAI Chat Completions APIへ送信し、今の髪型をセットする案と美容室でカットする案を各5つ提案します。トレンドの方向性はAIの一般知識に基づき、リアルタイム検索や人気ランキングではありません。写真から見える輪郭の目安であり、骨格診断や仕上がりを保証するものではありません。自撮り写真はセッション中だけ保持し、画面の「自撮り写真と診断結果を削除」から消去できます。髪型イメージのボタンを押すと、選んだ髪型と自撮り写真をOpenAI Images APIの画像編集機能へ送り、本人らしさを保った前・横・後ろの合成画像を生成します。画像での本人の再現は保証されません。診断は1回、髪型イメージ生成は案ごとにAPI利用料が発生する場合があります。画像生成は選択式で、一度に10枚を自動生成しません。

お気に入りサイトはサイト名・URL・グループをTursoのSQLite互換データベースに保存し、サイト利用者全員で共有します。グループ名は自由に追加でき、グループごとにタブで絞り込めます。サイト名とグループは登録後も編集できます。ログインはなく、アプリを利用できる人は閲覧・追加・編集・削除できます。データはRenderのファイル領域ではなく外部データベースに保存するため、Renderの再起動・再デプロイでは消えません。Turso側の利用枠・サービス条件は適用されます。詳細は[Turso Python quickstart](https://docs.turso.tech/sdk/python/quickstart)を参照してください。

天気はAPIキー不要の[Open-Meteo Forecast API](https://open-meteo.com/en/docs)を使います。現在気温・体感温度・最高／最低気温などを画面に表示し、提案にも含められます。予報はアプリ内で1時間キャッシュしてリクエスト数を抑えます。予報を取得できない場合は、[Open-Meteo Archive API](https://open-meteo.com/en/docs/historical-weather-api)から前年同月の日平均気温を取得して月平均を計算し、今日の実況・予報ではない季節参考値として提案に使います。この場合、取得できていない降水・風・湿度は推測しません。予報・履歴の両方を取得できない場合は、その旨を表示し、季節感をもとに提案します。HTTP 429（アクセス上限）時は、同じエンドポイントへの再試行を待機時間中抑制します。トレンドは出典を確認した編集テーマで、リアルタイムの検索・売上ランキングではありません。

海外トレンドの参照先: [Fashionista — Fall 2026 street style](https://fashionista.com/2026/03/street-style-trends-fall-2026)、[British Vogue — Autumn/Winter 2026](https://www.vogue.co.uk/autumn-winter-2026)。トレンドスナップショットは2026年10月12日更新です。
